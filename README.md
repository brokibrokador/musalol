# MUSAlol

Cliente desktop de League of Legends com stats, champ select, runas/builds e overlays.

## Releases

- **v1.0.2 (latest):** champ select dentro da página Ao Vivo, counters por campeão e updater automático.
- **v1.0.1:** runas/builds expandidas, builds de pro players/OTPs e editor de runas no champ select.
- **v1.0 (arquivado):** build original mantido para registro em `releases/tag/v1.0`.

O binário é distribuído apenas como `MUSAlol.exe` portátil. Sem código-fonte do app neste repositório.
